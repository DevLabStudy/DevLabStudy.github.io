DevLabStudy Installer v0.1-beta

An interactive, terminal-based package installer (TUI) designed for Debian and Ubuntu Linux systems.

About the Project

dinstall (package name: devlab-installer) is a lightweight CLI utility built to streamline software provisioning on fresh Linux installations, Proxmox LXC containers, and homelab test benches. Powered by whiptail, it provides a clean Text User Interface (TUI) to select, search, and install essential software packages without re-typing lengthy apt commands.

Key Features

  • Categorized Presets: Pre-configured lists for System Utilities, Services & Servers, and Networking/Homelab tools.
  • APT Repository Search: Live search directly against Debian/Ubuntu package archives via apt-cache.
  • Batch Installation: Accumulate software selections across multiple categories before executing a single combined installation.
  • Privilege Aware: Automatically handles execution under both root and sudo environments.

🚀 Installation Commands

Option 1: Quick Install via cURL (Recommended) 

curl -sSL https://www.devlabstudy.ovh/assets/downloads/install.sh | bash

Option 2: Quick Install via Wget 

wget -qO- https://www.devlabstudy.ovh/assets/downloads/install.sh | bash

Option 3: Manual .DEB Package Download & Installation 

wget https://www.devlabstudy.ovh/assets/downloads/devlab-installer.deb
sudo apt update && sudo apt install -y whiptail python3
sudo dpkg -i devlab-installer.deb || sudo apt-get install -f -y
rm -f devlab-installer.deb

After successful installation, launch the TUI application by executing:

dinstall
