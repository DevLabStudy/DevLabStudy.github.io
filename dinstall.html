DevLabStudy Installer v0.1-beta

An interactive, terminal-based package installer (TUI) designed for Debian/Ubuntu Linux systems.

About the Project

dinstall (package name: devlab-installer) is an open-source CLI utility built to streamline software provisioning on newly installed Linux machines, homelab nodes, and test benches. It provides a clean Text User Interface (TUI) powered by whiptail, allowing users to rapidly select, search, and install software packages without typing lengthy terminal commands.

Key Features

  • Categorized Selection: Organized software presets including System Utilities, Server Services, and Homelab & Networking tools.
  • APT Search Integration: Search for any package available in Debian/Ubuntu repositories directly within the TUI.
  • Stateful Selection: Select packages across multiple categories or search queries before executing a single combined installation batch.
  • Dynamic Scaling & Root Safety: Auto-scales to terminal window dimensions and seamlessly handles both root and non-root (sudo) environments.

Quick Installation

Run the following one-liner command in your terminal to automatically download, install dependencies, and configure dinstall:

curl -sSL https://devlabstudy.ovh/assets/downloads/install.sh | bash

Once the setup is complete, launch the installer by typing:

dinstall
